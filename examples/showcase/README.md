# Demonstração pública original

`demo.mp4` foi gerado por `npm run demo`: 10 segundos, 1080×1920, 30 FPS, H.264, sem faixa de áudio. Gráfico, linha do tempo, cenário e personagens são procedurais originais. Dados numéricos são apenas ilustrativos. Não contém roteiro, voz, mídia de terceiros ou dados de pacientes.

O arquivo serve de amostra para download sem depender de executar ferramentas. `demo.mp4.report.json` registra a verificação local por FFprobe/FFmpeg. Reexecute o pipeline para reproduzir o material. O MP4 não comprova alinhamento acústico ou uma produção real narrada.
